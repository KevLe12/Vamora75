Vamora75 is designed by **Kevin Le, Sammy DeGraaff and Mohammed-Mehdi Hamdaoui** (team Vamora).
Every deliverable is generated by the scripts in `Source/`. The inputs and third-party material are
listed below. Keep this file and `Licenses/` when you share the project.

## Project inputs (supplied by the team)

- **Keyboard75 / Keyboard75_Exploded_ANSI** (local project): the 82-key exploded 75 % layout, key
  positions and PCB outline. Rev 1.0 keeps the layout. Its schematic, matrix, controller and
  routing were all replaced. Original notes: `Reference/Keyboard75_README.md`.
- **Aster75** (local project): the two-piece tab-gasket case approach used in rev 0.1. Rev 1.0
  rebuilt the case with new code and dimensions. Its attribution is in `Reference/Aster75_ATTRIBUTION.md`.
  Aster75 credits **The Manta75** by Eric Becourt (mymakercorner), hardware licensed CC BY 4.0
  (https://github.com/mymakercorner/the_manta75). The licence is in `Licenses/`.
- **Rev 0.1** (`Archive/rev0.1/`) also used ai03's MX_V2 library (MIT, `Licenses/MX_V2_LICENSE.txt`)
  and the Waveshare RP2040-Zero.

## ScottoKicad (Joe Scotto) - used from rev 1.1

Rev 1.1 uses footprints and 3D models from Joe Scotto's **ScottoKicad** library
(https://github.com/joe-scotto/scottokeebs, local copy `A:\ScottoKicad`), copied into
`PCB/Vamora75.pretty` and `PCB/3dmodels` so the project opens without the library installed:

- `Hotswap_MX_1.00u` ... `Hotswap_MX_6.25u`: MX switch + Kailh CPG151101S11 hot-swap socket
  footprints, with the `Hotswap_MX.step` socket model and `MX_PCB.step` switch model.
- `Stabilizer_MX_2.00u`, `Stabilizer_MX_6.25u`: PCB-mount stabiliser footprints and models.
- `Diode_SOD-123`, `USB_C_HRO_TYPE-C-31-M-12`, `Resistor_0402`, `Capacitor_0402`,
  `ESD_SOT-23-6`, `Voltage_SOT-23`, and the diode and USB-C models.
- `MX_*_CAD.step` keycap models (rev 1.1 renders and assembly only; rev 1.2 uses generated
  sculpted keycaps instead).

Changes made in the copies: re-saved in KiCad 10 format; USB-C shield pads renamed `S1` to
`SH` to match KiCad's USB-C symbol; stabiliser holes turned into plated holes with copper
reinforcement rings (4.6 / 6.0 mm, rev 1.2) and B.Cu keep-outs 0.5 mm beyond the rings; the MX
switch model added to the hot-swap footprints; 3D-model paths pointed at `${KIPRJMOD}/3dmodels`. Per ScottoKicad's README, its parts come from several libraries, mostly
licensed CC-BY-SA 4.0: KiSwitch (switches, stabilisers, sockets), Keebio, Kleeb, Marbastlib,
Adafruit and others. See `Licenses/ScottoKicad-NOTICE.md`. Check the individual upstream
libraries before redistributing the library files themselves.

## Third-party data (rev 1.0, still used)

- **KiCad 10 libraries**: the stock footprints and 3D models for QFN-56 (RP2040), USON-8, crystal,
  0603 capacitors, fuse, test pad, fiducial and TS-1187A, plus the 0402/SOT-23 models.
  They are licensed CC-BY-SA 4.0 with the KiCad design exception (`Licenses/KiCad-library-license.md`).
  The files are copied into `PCB/Vamora75.pretty` and `PCB/3dmodels` so the project is
  self-contained.
- **Plate stabiliser openings**: based on the "MX simple" profile from ai03's plate generator
  (https://github.com/ai03-2725/another-keyboard-builder), widened to 7.0 mm in rev 1.2. Only the
  published dimensions are used; they are reimplemented in `Source/vamora_mech.py`.
- **Reference circuit**: the RP2040 core circuit (crystal, flash, decoupling, USB) follows Raspberry
  Pi's "Hardware design with RP2040" guide and the Pico design. The part numbers are the same ones
  Raspberry Pi uses.
- **Fonts**: the "Vamora75" name and the small labels are glyph outlines from **Segoe UI Black /
  Segoe UI Bold** (Microsoft, shipped with Windows), shaped with HarfBuzz and converted with
  fontTools. Only vector outlines appear in the outputs; no font file is redistributed. To use an
  open font, point `SEGOE_BLACK`/`SEGOE_BOLD` in `Source/vamora_logo.py` at, for example, Noto Sans
  (SIL OFL) and rebuild.
- **Nam Quốc Sơn Hà** (PCB bottom silkscreen): a medieval poem in the public domain, in the common
  Hán-Việt transcription, set in Segoe UI Bold.
- **QMK Firmware** is GPL-2.0-or-later (https://github.com/qmk/qmk_firmware, `Licenses/QMK-LICENSE.txt`).
  The keyboard definition in `Firmware/qmk` is provided under the same licence. The QMK core is not included.
- **CircuitPython** (MIT, `Licenses/CircuitPython-LICENSE.txt`): the user downloads the official
  Raspberry Pi Pico UF2 from circuitpython.org. The four `.py` files in `Firmware/CircuitPython` are
  original.
- **Manufacturer and part names** (Raspberry Pi, Winbond, Kailh, HRO, Abracon, STMicroelectronics,
  Torex, XKB, JLCPCB/LCSC, Poron) identify compatible parts only. No endorsement is implied.

## Original work in this project

The case and plate design, the PCB design, the sculpted keycap models, the renders and all
`Source/` scripts were created for Vamora75 (the rev 1.0 badge artwork is kept in
`Archive/rev1.0_outputs.zip`). The AnnovaX75 project by Arnav Kumar (AGPL-3.0) was looked at as a
reference for presentation only; none of its files are used. No new licence is claimed
over third-party inputs beyond their own notices.
