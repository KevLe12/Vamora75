# ScottoKicad - notice

Footprints and 3D models in `PCB/Vamora75.pretty` and `PCB/3dmodels` whose names start with
`Hotswap_MX_`, `Stabilizer_MX_`, `Diode_SOD-123`, `USB_C_HRO_TYPE-C-31-M-12`, `Resistor_0402`,
`Capacitor_0402`, `ESD_SOT-23-6` and `Voltage_SOT-23` (plus `Hotswap_MX.step`, `MX_PCB.step`,

**ScottoKicad** by Joe Scotto (rev 1.1 also used his keycap models; rev 1.2 does not):
https://github.com/joe-scotto/scottokeebs

- KiCad-RP-Pico - https://github.com/ncarandini/KiCad-RP-Pico
- kicad-lib-arduino - https://github.com/g200kg/kicad-lib-arduino
- Marbastlib - https://github.com/ebastler/marbastlib
- Kleeb - https://github.com/crides/kleeb
- Keebio-Parts.pretty - https://github.com/keebio/Keebio-Parts.pretty
- Adafruit_CAD_Parts - https://github.com/adafruit/Adafruit_CAD_Parts

The modifications made for Vamora75 are listed in `ATTRIBUTION.md`. Where CC-BY-SA 4.0 applies,
redistributed copies of these library files keep that licence.
