# Vamora75 sources

Every deliverable in this repository is generated by the scripts in this folder from a few
parameter files. Edit the parameters, rerun, and every file (PCB, plate, case, firmware,
artwork, manufacturing outputs, renders, reports) stays consistent.

```
python -m venv .venv && .venv\Scripts\pip install -r Source\requirements.txt
.venv\Scripts\python Source\build_all.py              # everything, ~8 min (PCB routing ~3 min)
.venv\Scripts\python Source\build_all.py --skip-pcb   # keep the routed board, rebuild the rest
.venv\Scripts\python Source\build_all.py --footprints # also regenerate footprints + 3D models
```

KiCad 10.0.6 must be installed at `C:\Program Files\KiCad\10.0` (paths are at the top of
`build_pcb.py`, `build_all.py`, `export_manufacturing.py`). Joe Scotto's **ScottoKicad** library
is read from `A:\ScottoKicad` (set `VAMORA_SCOTTO` to move it). You only need it to regenerate
footprints (`--footprints`) and for the keycap models in the assembly STEP; the project already
carries copies of everything it uses. The Segoe UI fonts ship with Windows; any TTF works
(constants in `vamora_logo.py`).

## Parameter files (edit these)

| File | Controls |
|---|---|
| `vamora_layout.py` | key positions and sizes, keycodes, matrix row/column of every key, RP2040 GPIO map, stabiliser spacing, PCB size |
| `pcb_plan.py` | placement of diodes and of every controller part (board coordinates), fan-out rule areas |
| `vamora_mech.py` | Z stack, plate tabs, gaskets, case margins, screws, USB tunnel, typing angle, plate cut-outs, print split |
| `vamora_logo.py` | the "Vamora75" name (`name_text`, Segoe UI Black), text shaping, palette (the rev 1.0 badge code is still there, unused) |

## Pipeline

| Step | Script | Output |
|---|---|---|
| Footprints + 3D models | `gen_footprints.py`, `upgrade_footprints.py` (KiCad Python) | `PCB/Vamora75.pretty`, `PCB/3dmodels`: ScottoKicad hot-swap (with his MX switch model), stabiliser, diode, USB-C and passive footprints and models; KiCad stock RP2040, flash and crystal parts; a generated TS-1187A model. Re-saved in KiCad 10 format with stabiliser keep-outs. |
| Schematic | `gen_schematic.py` | `PCB/Vamora75.kicad_sch` + project symbol library |
| Project / rules | `gen_project.py`, `make_board_plan.py` | `.kicad_pro` (net classes, JLCPCB limits), `.kicad_dru` (0.15 mm only inside fan-out areas) |
| Routing | `route_board.py` (+ `router.py`) | `PCB/build/routes.json` - deterministic: rows on B.Cu, columns on F.Cu, controller fan-out by a grid A* router with clearance fields |
| Checks | `check_connectivity.py` | connectivity + clearance before KiCad sees the board |
| Board | `kicad_build.py` (KiCad Python) | `PCB/Vamora75.kicad_pcb` - footprints, nets, tracks, vias, GND pours, rule areas, artwork |
| Silkscreen art | `extract_obstacles.py` (KiCad Python), `gen_artwork.py` | front: a very large "Vamora75" across the middle (knocked out around holes and pads); back: *Nam Quốc Sơn Hà* centred under the F-row plus BOOT/RESET/rev labels, readable from below |
| DRC / ERC | `build_pcb.py` (orchestrates all of the above) | `validation/erc.json`, `validation/drc.json` |
| Plate | `build_plate.py`, `kicad_plate.py` | `Mechanical/Plate/*` DXF/STEP/STL, `Plate/*.kicad_pcb` |
| Case | `build_case.py` | `Mechanical/Case/*`, `Mechanical/Soft/*`, `Mechanical/Vamora75_assembly.step`, `validation/mechanical.json` (input: a switch-free PCBA STEP that `build_all.py` exports from a temporary copy of the board) |
| Renders | `render_previews.py` | `Previews/*.png` (VTK) + KiCad renders (`pcb_top` bare, `pcb_top_switches` with Scotto's switches, `pcb_bottom`) |
| Manufacturing | `export_manufacturing.py` | Gerbers, drill, JLCPCB BOM/CPL, PDFs, plate Gerbers, kit BOM |
| Firmware | `gen_firmware.py`, `test_firmware.py` | QMK/VIA/CircuitPython/KLE + `validation/firmware.json` |
| Artwork | `export_artwork.py` | `Artwork/*`: "Vamora75" name SVG/PNG/DXF + overview sheet |
| Layout data | `export_layout.py` | `layout.json`, `Mechanical/key_positions.csv`, `Previews/layout.png` |
| Report | `build_all.py` | `validation/STATUS.md` |

Helpers: `sexp.py` (KiCad s-expressions), `kicad_fp.py` (footprint pad geometry in board
coordinates; bottom side = mirror then rotate, verified against pcbnew), `router.py`.

## Changing things safely

* **Moving a key or changing the matrix**: edit `vamora_layout.py`, run `build_all.py`. Routing of
  the matrix is regenerated; check `validation/STATUS.md` for zero DRC/unconnected items.
* **Moving controller parts**: `pcb_plan.py`; the hand-guided fan-out in `route_board.py` refers to
  pad positions, so re-check the DRC carefully.
* **Different typing angle / case height**: `vamora_mech.py` (`TYPING_ANGLE`, `CASE_TOP`, `FLOOR_Z`) -
  `build_case.py` re-runs every interference check.
* The KiCad files are normal KiCad 10 files: you can also edit them by hand in KiCad. A later
  `build_pcb.py` run overwrites the schematic and board, so either keep working in KiCad from then
  on or port the change into the generators.

`Archive/rev0.1/Source` holds the rev 0.1 scripts (module-based board, flat case) for reference.
